# VF-002 — Agent configurations

Status: implementation and automated checks passed; owner manual acceptance pending.
Depends on VF-001, whose owner manual acceptance also remains pending.

Goal: an operator can create an agent and publish its configuration.
Implement the configuration schema, import/export, drafts, immutable versions,
environment bindings, a minimal editor UI, and audit events.

Acceptance criteria:
- Invalid configurations are rejected with actionable errors.
- Published versions cannot be edited.
- Activation is atomic; concurrent editing conflicts are explicit.
- Rollback switches the binding to a previous compatible version.
- Exports contain no secrets.
- Viewers cannot modify configurations.

Tests: schemas, access control, publication, concurrency, and rollback.
Manual verification: create v1, edit a draft, publish v2, activate v2,
and switch back to v1.
