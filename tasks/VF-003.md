# VF-003 — Voice playground

Status: todo. Depends on VF-002.

Prerequisites: select providers, a budget, language, and LiveKit hosting mode.
Supply credentials locally; never store them in Git.

Goal: a real browser voice conversation using the selected agent version.
Implement scoped token issuance, dispatch, the worker, the voice pipeline,
session start/end, transcripts, errors, and metrics.

Acceptance criteria:
- The user hears a real response; a text mock does not validate audio.
- The session pins its version; publishing another version during the
  conversation does not change the active session.
- Interruptions and disconnections are handled.
- Provider unavailability is reported as an error and resources are released.
- Unauthorized users cannot obtain room tokens.
- Session duration is limited.

Tests: controlled substitutes in CI, a separate live smoke test,
and manual interruption testing.
Report provider/model versions, latency, and measurement conditions.
Out of scope: Twilio, outbound calls, and production deployment.
