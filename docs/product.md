# Продукт і межі

## Модель
Публічне ядро для self-hosted розгортання. Окремий deployment клієнта:
панель, API, voice worker, база, секрети та бізнес-інтеграції.
Клієнт може розгорнути продукт сам або отримати налаштовану інсталяцію.
Майбутнє дерево проєктів у центральній борді не є структурою Git-гілок.

## MVP
- Вхід оператора та ролі admin/operator/viewer.
- Налаштування агентів і брендингу.
- Чернетки, публікація версій, активація й повернення конфігурації.
- Голосовий playground у браузері як перший технічний рубіж.
- Вхідна телефонія: LiveKit + Twilio/SIP як запланована інтеграція.
- Історія сесій, транскрипти, виклики інструментів, помилки.
- Тести й звіти; демонстраційний автосервіс після основи.
- Документований запуск незалежної інсталяції.

## Поза MVP
Вихідні кампанії, центральний AI-оператор, керування серверами,
довільний запуск стороннього коду, маркетплейс інтеграцій, білінг SaaS.

## Приймання продукту
Запустити дві незалежні інсталяції з різним брендингом і даними.
Провести реальну розмову та тестову бізнес-операцію.
Простежити конфігурацію, виклики й результат сесії.
Перевірити публікацію нової версії та rollback для нових сесій.
Повторити запуск за README без прихованих ручних налаштувань.
